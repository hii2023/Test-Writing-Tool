# NOSH7 Sales Engine — Test Writing Tool

A **mobile-first sales messaging and script tool** for the NOSH7 sales team — designed for use on the go, during calls, and while chatting with prospects on WhatsApp.

## What It Does

Gives NOSH7 sales reps a quick-access interface for sales scripts, message templates, and objection-handling responses — so every conversation follows a proven, consistent approach.

## Key Features

- **Sales script interface** — step-by-step conversation guide for NOSH7 sales calls
- **Message templates** — pre-written WhatsApp messages for common scenarios
- **Objection handling** — tested responses to the most common customer objections
- **Mobile-first layout** — optimized for phone screens, one-handed use
- **Instant access** — no login, opens immediately
- **Lightweight** — fast load on any mobile connection

## Tech Stack

- HTML, CSS, Vanilla JavaScript

## Audience

NOSH7 sales reps handling inbound and outbound customer conversations on WhatsApp and phone.
